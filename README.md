# 📄 Free Invoice Generator

পেইড ইনভয়েস টুলের আর দরকার নেই!  
এই টুল দিয়ে আপনি **ফ্রিতে** প্রফেশনাল PDF Invoice বানাতে পারবেন।

Live Demo বানাতে চাইলে নিচের ধাপগুলো ফলো করুন।

---

## ✨ Features

- সুন্দর ও প্রফেশনাল PDF Invoice
- একাধিক আইটেম যোগ করা যায়
- Tax / VAT হিসাব
- BDT, USD, EUR সাপোর্ট
- Invoice Number, Date, Due Date সেট করা যায়
- সম্পূর্ণ ফ্রি ও ওপেন সোর্স

---

## 🚀 কিভাবে চালাবেন (লোকাল)

### ১. রিপোজিটরি ক্লোন করুন
```bash
git clone https://github.com/YOUR_USERNAME/free-invoice-generator.git
cd free-invoice-generator
```

### ২. ভার্চুয়াল এনভায়রনমেন্ট তৈরি করুন (ঐচ্ছিক কিন্তু রেকমেন্ডেড)
```bash
python -m venv venv
# Windows
venv\Scripts\activate
# Mac/Linux
source venv/bin/activate
```

### ৩. প্যাকেজ ইনস্টল করুন
```bash
pip install -r requirements.txt
```

### ৪. অ্যাপ চালু করুন
```bash
streamlit run app.py
```

ব্রাউজারে `http://localhost:8501` খুলবে।

## ☁️ ফ্রিতে ডিপ্লয় করুন (Streamlit Cloud)

1. এই রিপোজিটরি আপনার GitHub অ্যাকাউন্টে Fork বা Upload করুন
2. [share.streamlit.io](https://share.streamlit.io) এ যান
3. "New app" ক্লিক করুন
4. আপনার GitHub রিপো সিলেক্ট করুন
5. Main file path: `app.py`
6. Deploy করুন!

কয়েক মিনিটের মধ্যে আপনার লাইভ লিংক পেয়ে যাবেন।
